What is actually measured

The interesting number is not accuracy.

A demo that says “100% correct” is measuring itself against its own rule engine. The numbers worth reading are the ones where the pipeline stopped: the cases it sent to a human, and the checkpoints that failed because a required record did not exist.

Questions people actually ask

Before you order.

Is the demo a real product I can use?

No. TriageOps is a portfolio demonstration over synthetic manufacturing documents generated by a fixed seed. It exists to show the architecture and the failure behaviour, and the repository says so at the top.

Why is there no accuracy percentage?

Because no evaluation has been run against your data yet. The demo’s 100% decision match is a consistency check against the same rule engine that produced the expected answers — it is not evidence of accuracy on unseen cases.

Do we need a video call?

No. Everything is written: scope, baseline, findings, handover. If your procurement process requires a call, say so in the job post and it can be arranged — but the default is asynchronous.

What do you need from me to start?

For the $150 report: the documents your assistant currently uses, and 20 questions with the answers you would accept. For the builds: the same corpus, plus one sentence on who reads the output.

What happens if the documents are confidential?

Work can run on a de-identified sample, on your machine via a script you run, or on a subset you approve. No client data is published — the demo screenshots use synthetic records only.

Which providers does this work with?

The LLM layer is an interface with three adapters: a deterministic mock, OpenAI, and Anthropic. Retrieval is local BM25 + TF-IDF, so the stack does not depend on a hosted vector database.
